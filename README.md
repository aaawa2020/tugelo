# 涂个乐 · Tugelo

和好友在线玩你画我猜的中文网页游戏：2–8 人同乐，无需注册、无需下载，打开链接就能开局。

**在线游玩：https://aaawa2020.github.io/tugelo/**

## 玩法介绍

1. 房主创建房间，得到一个 **6 位房间码**（也可以直接复制邀请链接）
2. 把房间码或链接发给好友，好友输入昵称即可加入
3. 人齐后房主开始游戏，每轮轮流一人画画、其余人猜词
4. 全部轮次结束后公布总分排名

## 对局规则

| 项目 | 规则 |
| --- | --- |
| 人数 | 2–8 人（最少 2 人开局） |
| 轮次 | 可选 1–5 轮，默认 3 轮 |
| 选词 | 每回合画画者先在 18 秒内从 3 个备选词中选一个 |
| 画画限时 | 每回合 75 秒 |
| 猜词者计分 | 猜对得 30 分基础分 + 按剩余时间折算最高 70 分，越快越高（31–100 分） |
| 画画者计分 | 每被一位玩家猜中，得 20 分 |
| 结算 | 每轮结束展示答案与本轮得分（5 秒），全部轮次结束公布最终排名 |

防泄题设计：画画者和已经猜中的玩家，在本回合内不能在聊天框发言。

## 功能特性

- **实时画板**：画笔 / 橡皮、9 种蜡笔色（墨水黑、番茄红、蜜桃粉、阳光橙、柠檬黄、薄荷绿、天空蓝、葡萄紫、牛奶白）、4 档笔刷粗细、撤销（支持 `Ctrl+Z`）、一键清空；笔触实时同步给房间内所有人，鼠标和触屏都可画
- **聊天猜词**：在猜词框输入答案即可抢答，猜对立即提示并计分；猜词者只能看到词语类别和字数，看不到答案
- **词库**：约 90 个中文词，分动物、食物、日常、地方、动作 5 类
- **房间机制**：6 位房间码由字母数字组成，已剔除 I、O、0、1 等易混淆字符；断线有 22 秒重连宽限；房主离开后房主身份自动转移给下一位玩家（房主彻底断开则房间解散）
- **零门槛**：昵称保存在浏览器本地，下次打开不用重输；整个游戏不需要注册账号

## 技术架构

纯静态前端，**无后端、无构建、无依赖安装**，原生 HTML + CSS + JavaScript（ES 模块），不使用任何框架。

- **房主即服务器**：GitHub Pages 版本通过 [PeerJS](https://peerjs.com/) 信令建立 WebRTC 数据连接，对局状态全部由房主浏览器维护，其他玩家直连房主同步状态——所以**房主必须保持游戏页面打开**
- **传输层**（`pages-peer.js`）：PeerJS 1.5.5（cdnjs 优先、jsdelivr 备用），配合 Google STUN 与 PeerJS TURN 中继打通浏览器直连；画画笔触分批发送（55 个点或 110ms 一批），并辅以轮询同步（画画时约 430 ms、平时约 900 ms）
- **规则引擎**（`rules.js`）：词库、回合推进、计分与合法性校验独立成模块，与界面解耦
- **双模式联网**：同一套 `client.js` 既支持 GitHub Pages 的 PeerJS 模式，也预留了自托管 API 模式（`fetch /api/rooms`，本仓库未包含服务端代码）
- **校验与限流**：笔触颜色 / 粗细 / 点数（单笔 ≤ 70 点、每回合 ≤ 2500 笔）、昵称 ≤ 16 字、聊天 ≤ 80 字且 600 ms 一条、单条消息 ≤ 12,000 字节等均有校验；发给非画画者的状态快照会隐藏答案
- **视觉风格**：暖色纸面 + 蜡笔质感，字体使用 Noto Sans SC 与 Baloo 2，画布逻辑坐标 1000 × 660

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 游戏唯一页面（入口），引入字体与各模块 |
| `client.js` | 游戏主逻辑：画板、房间、轮询同步、计分、界面 |
| `rules.js` | 对局规则引擎：词库、回合、计分、校验 |
| `pages-peer.js` | PeerJS 传输层：GitHub Pages 模式的联网实现 |
| `style.css` | 全部样式：纸面底色、蜡笔配色等视觉变量 |
| `.nojekyll` | 空文件，让 GitHub Pages 跳过 Jekyll、原样发布静态文件 |

## 本地运行

无需安装任何依赖，克隆后用任意静态服务器托管根目录即可：

```bash
git clone https://github.com/aaawa2020/tugelo.git
cd tugelo
npx serve .
```

也可以直接用浏览器打开 `index.html`（联网对局需要能访问 PeerJS 云信令服务）。

## 部署

本仓库已启用 GitHub Pages：推送到 `main` 分支后自动重新部署，线上地址为 https://aaawa2020.github.io/tugelo/ 。

## 已知限制

- 房主关掉页面或彻底断线，房间即解散（房主身份转移仅适用于房主正常离开的情形）
- WebRTC 直连受双方网络环境影响，个别网络下可能需要 TURN 中继，连通性不如中心服务器稳定
- 词库为内置固定词表，暂不支持自定义词库
